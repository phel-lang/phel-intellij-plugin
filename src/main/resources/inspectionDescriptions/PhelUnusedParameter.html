Reports a function parameter that the body never reads.

Applies to defn, defn-, fn, defmacro and defmacro-.

Example:


(defn greet [name greeting]   ;; 'greeting' is reported: Parameter 'greeting' is never used.
  (println name))

Ignored names

Names conventionally used to discard a value are never reported: _, any name starting with _, and names starting with & (rest markers).

No quick-fix is offered: removing a parameter changes the function's arity, so every call site would have to change with it.
