Reports the |(...) short function, which Phel 0.50 removed in favor of #(...). From 0.50 on, | is an ordinary symbol and the list after it a call of its own, so the code no longer means what it says.

RemovedWrite instead
|(inc $)#(inc %)
|(+ $1 $2)#(+ %1 %2)
|(apply str $&)#(apply str %&)

The quick-fix Convert to #(...) respells the function and its own placeholders. It is not offered when the body already holds a #(...), which converting would nest inside another.
